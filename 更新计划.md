# Mobile Task Distribution Plan

> Single source of truth for ongoing work across the mobile app, web dashboard, and shared packages. This replaces the previous mixed-language version to avoid future encoding issues.

## Objectives

- Ship a consistent publish → execute → review loop on both clients, optimized for mobile-first classrooms.
- Keep every new surface bilingual (EN + ZH) by updating `apps/mobile/src/i18n/en.json` and `zh.json` together.
- Harden attachments, offline caching, and analytics so teachers can trust the system during live sessions.
- Expose clear organization context (role, member count, switch costs) everywhere tasks are managed.
